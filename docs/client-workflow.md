# Клиенты и бланки

Основной интерфейс реализован на JavaFX. В бланке клиент выбирается по контакту,
ФИО или названию организации. При замене клиента очищаются велосипед и контакт,
после чего для нового клиента автоматически выбираются первые доступные значения.

Карточки клиентов и велосипедов сохраняются отдельно от бланка. Изменения справочника
не переписывают уже сохранённый снимок бланка: действие «Обновить данные» подготавливает
новый снимок, который применяется при сохранении бланка.

Визуальная структура и настройка экранов находятся в FXML-файлах
`src/main/resources/org/bike/fx`. Запуск и редактирование форм описаны в
[`javafx.md`](javafx.md).
