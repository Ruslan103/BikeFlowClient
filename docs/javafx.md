# JavaFX-интерфейс

Основной `org.bike.Main` запускает JavaFX-приложение. Требуются JDK 21 и OpenJFX 21.0.13;
Maven загружает JavaFX автоматически.

## Запуск

Из IDEA/NetBeans запустите Maven-цель `javafx:run` либо:

```powershell
mvn package
./run-javafx.ps1
```

При переносе JAR на другой компьютер рядом с ним должна находиться папка `lib`
из `target`. Для поставки вместе с Java выполните:

```powershell
./tools/build-app-image.ps1
```

Готовый `CraftBiker.exe` находится в `target/package-<дата-время>/CraftBiker`.
Копировать нужно всю папку `CraftBiker`. Установка JDK на рабочем месте не требуется.
Сборка app-image выполняется на Windows с JDK 21 и не требует WiX.

## Редактирование визуала

Откройте FXML из `src/main/resources/org/bike/fx` непосредственно в Scene Builder:

| Файл | Экран |
|---|---|
| `Shell.fxml` | Оболочка, профиль, нижняя навигация |
| `WorkOrder.fxml` | Бланк по исходному согласованному макету |
| `Clients.fxml` | Справочник и выбор клиента |
| `ClientEditor.fxml` | Карточка клиента: основное, контакты, велосипеды |
| `BicycleEditor.fxml` | Карточка велосипеда |
| `Catalog.fxml` | Услуги и история цен |
| `Discounts.fxml` | Создание, изменение и удаление скидок |
| `Profiles.fxml` | Локальные профили подключения |
| `Login.fxml` | Вход в профиль |
| `Settings.fxml` | Общий адрес сервера |

Каждая форма сама подключает соседний `theme.css`. Он задаёт общий фон `#F8F8F8`,
шрифт Segoe UI, размеры отступов, плоские кнопки и оформление карточек.
FXML содержит все компоненты, вложенность, размеры, подписи, векторные значки
и ссылки на обработчики. Контроллеры не перестраивают расположение после загрузки.
Конструкторы контроллеров не обращаются к серверу; подключение выполняется через `bind`.
Не удаляйте `fx:id` и `onAction`, если соответствующие поля/обработчики используются контроллером.
При редактировании сохраняйте FXML в UTF-8 без BOM.

В IDEA можно указать путь к Scene Builder в настройках JavaFX. В NetBeans откройте
FXML через установленный Scene Builder. В проекте остались JavaFX-экраны в FXML;
старые Swing-панели и NetBeans `.form` удалены.
Изменения FXML применяются при следующем запуске; промежуточного генератора разметки нет.

## Ответственности

- `fx/api/FxConnection` — фоновый HTTP, сессия/CSRF и доставка результатов в поток JavaFX.
- `fx/*/*Controller` — отображение, сбор ввода, состояния запросов и пользовательские действия.
- `fx/workorder/TrelloFields` — чтение досок/колонок/меток и состояния карточки из Trello
  через сервер; обновление каждые 30 секунд сохраняет несохранённый выбор пользователя.
- Сервер — валидация клиента, совпадения, принадлежность контакта/велосипеда, версии,
  цены/скидки, сохранение снимка и формирование содержимого карточки Trello.

Сохранение бланка передаёт выбранные ID и версии, а не изменения карточек клиента.
Редактирование справочника выполняется отдельным сохранением карточки. Действие
«Обновить данные» подготавливает новый снимок; он сохраняется вместе с бланком.
При HTTP 409 ввод остаётся, карточку можно явно перечитать.

При повторном входе в тот же профиль открытая страница и ввод сохраняются.
Смена профиля проверяет наличие несохранённого бланка и очищает представления предыдущей сессии.

## Проверки без рабочего сервера

Все проверки, включая реальный запуск главного окна, можно выполнить одной командой:

```powershell
./tools/verify-javafx.ps1
```

Проверка запуска кратковременно открывает главное окно, читает список локальных профилей
и закрывает приложение. Вход на рабочий сервер не выполняется.

```powershell
mvn test-compile dependency:build-classpath '-Dmdep.outputFile=target/fx-classpath.txt'
$classpath = 'target/classes;target/test-classes;' + (Get-Content target/fx-classpath.txt -Raw).Trim()
java -cp $classpath org.bike.fx.FxFormsSmokeCheck
java -cp $classpath org.bike.fx.FxWorkflowCheck
```

Первая проверка загружает все FXML/CSS и сохраняет изображения в `target/javafx-*.png`.
Вторая использует отдельный локальный HTTP-сервер и проверяет вход, предварительный
снимок клиента, сохранение бланка только по ID и сохранение ввода при конфликте версии.
Она не записывает профили, не обращается к рабочему серверу и не создаёт карточек в Trello.
