# CraftBiker — клиент Craft Bike

CraftBiker — настольное приложение для работы веломастерской. Клиент подключается к отдельно запущенному серверу Craft Bike, который хранит общую базу данных и предоставляет личный кабинет. Это руководство описывает запуск готового приложения, подключение к серверу и сборку Windows-приложения.

## Быстрый запуск готового клиента

### Шаг № 1. Убедитесь, что сервер запущен

Перед входом запустите сервер Craft Bike и PostgreSQL. Если сервер работает в Docker, проверьте его из папки **bike_server**:

~~~powershell
docker compose ps
~~~

Сервер должен быть доступен по HTTPS на порту **8443**. Для первоначальной загрузки публичного сертификата также доступен порт **8080**.

### Шаг № 2. Найдите папку приложения

Готовый пакет создаётся в каталоге:

~~~text
target\package-<дата-время>\CraftBiker
~~~

Например, собранный пакет содержит:

~~~text
CraftBiker\
  CraftBiker.exe
  app\
  runtime\
~~~

### Шаг № 3. Запустите приложение

Дважды щёлкните **CraftBiker.exe**.

Если переносите приложение на другой компьютер, скопируйте всю папку **CraftBiker**, а не один EXE: рядом с ним находятся файлы приложения и Java runtime. На компьютере пользователя отдельно устанавливать Java не нужно.

## Первое подключение к серверу

### Шаг № 1. Укажите адрес сервера

В приложении откройте **Настройки → Настройки сервера**. В поле **Адрес сервера** укажите:

- Если сервер и клиент работают на одном компьютере: **https://localhost:8443**
- Если сервер находится на другом компьютере: **https://<имя-или-IP-сервера>:8443**, например **https://192.168.1.20:8443**

Нажмите **Сохранить**. Клиент скачает публичный сертификат сервера.

> **localhost** означает текущий компьютер. Если сервер находится на другом устройстве, укажите его сетевое имя или IP-адрес.

### Шаг № 2. Проверьте сертификат

При первом подключении появится запрос на добавление нового сертификата и его SHA-256 отпечаток.

1. Сверьте отпечаток с указанным в разделе **HTTPS и сертификат** личного кабинета сервера.
2. Подтвердите добавление сертификата, если отпечатки совпадают и вы доверяете этому серверу.
3. Если отпечатки не совпадают, отмените добавление и проверьте адрес подключения и сертификат на сервере.

При самоподписанном сертификате клиент может получить его через HTTP endpoint на порту **8080**. Это нужно только для передачи публичного сертификата; после добавления приложение устанавливает HTTPS-соединение. Проверка отпечатка помогает убедиться, что был получен ожидаемый сертификат.

Сертификат сохраняется для имени или IP-адреса сервера в профиле пользователя Windows. Это доверие относится только к CraftBiker и не меняет доверие Chrome или всей Windows.

### Шаг № 3. Создайте профиль входа

Откройте вкладку **Профили** в нижней панели приложения и нажмите **Создать**. Заполните:

- **Название** — удобное имя подключения, например «Основной сервер».
- **Логин** и **пароль** — учётные данные, созданные администратором сервера.
- Поставьте **Профиль по умолчанию**, если приложение обычно подключается к этому серверу.
- Включите **Запомнить пароль**, если хотите, чтобы пароль сохранился на этом компьютере.

Нажмите **Сохранить**.

Адрес для профилей берётся из **Настройки → Настройки сервера**.

Сохранённый пароль защищается средствами Windows для текущей учётной записи. Профили и доверенные сертификаты не переносятся автоматически на другие компьютеры или учётные записи Windows.

Чтобы CraftBiker подключался автоматически при следующих запусках, включите **Запомнить пароль** и отметьте **Профиль по умолчанию**. Если профиль только один, он используется автоматически и без отметки по умолчанию.

### Шаг № 4. Войдите

Если пароль сохранён, клиент автоматически попробует войти в профиль по умолчанию при запуске. Если профиль не отмечен по умолчанию, пароль не сохранён или сервер недоступен, выберите профиль в верхней панели и нажмите **Войти / переподключить**. Введите пароль, если потребуется.

После успешного входа станут доступны разделы **Бланк**, **Клиенты**, **Услуги и цены**, **Скидки**, **Профили** и **Настройки**. Роли и доступы назначаются администратором на сервере.

## Обновление сертификата

Если администратор сервера заменил сертификат:

1. Убедитесь, что сервер уже использует новый сертификат и доступен по HTTPS.
2. В CraftBiker откройте **Настройки → Настройки сервера**.
3. Нажмите **Обновить сертификат**.
4. Сверьте новый SHA-256 отпечаток с кабинетом сервера и подтвердите его, если он совпадает.

Обновление сертификата не требует выхода из профиля или перезапуска CraftBiker. При смене сертификата обязательно проверяйте отпечаток.

## Сборка приложения для Windows

Сборка создаёт папку-приложение с EXE и встроенным Java runtime.

### Шаг № 1. Установите инструменты сборки

На компьютере разработчика нужны:

- JDK 21;
- Maven;
- Windows;
- полный JDK с утилитой **jpackage**.

### Шаг № 2. Откройте папку клиента

В PowerShell выполните:

~~~powershell
cd C:\Users\zaharovra\IdeaProjects\craft_bike\bike_display\craft_biker
~~~

### Шаг № 3. Соберите приложение

~~~powershell
.\tools\build-app-image.ps1
~~~

Скрипт соберёт JAR и подготовит Windows app-image с Java runtime и иконкой CraftBiker. Перед упаковкой из крупного исходника `src/main/resources/app-icon.png` автоматически создаются размеры `.ico` от 16×16 до 256×256 пикселей. Windows выбирает подходящий размер для EXE и созданного из него ярлыка, поэтому маленькая версия не растягивается на крупный значок. Та же эмблема отображается в окне приложения. После успешной сборки скрипт выведет путь к **CraftBiker.exe**.

Если Windows запрещает запуск PowerShell-скрипта политикой выполнения, можно временно разрешить запуск скриптов только в текущем окне PowerShell:

~~~powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\tools\build-app-image.ps1
~~~

### Шаг № 4. Передайте приложение пользователям

Передавайте всю папку **CraftBiker** из созданного каталога **target\package-<дата-время>**, например в ZIP-архиве. Не передавайте только **CraftBiker.exe**.

Сборка настроена для Windows и не является установщиком MSI: пользователь запускает EXE из распакованной папки. Для других операционных систем нужны отдельные сборки.

## EXE-установщик из GitHub

В репозитории GitHub откройте **Actions → Build Windows installer → Run workflow**. После успешной сборки установщик **BikeFlowClient-Setup.exe** можно скачать из раздела **Artifacts** этого запуска.

Чтобы создать релиз с установщиком в **Releases**, отправьте тег версии из папки проекта:

~~~powershell
git tag v1.0.0
git push origin v1.0.0
~~~

GitHub Actions соберёт Windows-установщик с Java runtime и опубликует его в созданном релизе. Установка выполняется для текущего пользователя; установщик добавляет ярлык в меню «Пуск» и на рабочий стол. Для сборки используются Windows runner, JDK 21 и WiX Toolset.

## Настройки и локальные данные

- Адрес сервера и настройки интерфейса сохраняются для текущего пользователя Windows.
- Профили хранят логин, выбранные роли и, если включён флажок **Запомнить пароль**, защищённый пароль.
- Сертификаты сервера хранятся отдельно для конкретного адреса.
- Данные приложения пользователя находятся в каталоге **%USERPROFILE%\.craft-biker**; удаление этих данных может сбросить локальные настройки и доверие к сертификатам.

## Устранение проблем

### Не удаётся подключиться к серверу

1. Проверьте, что сервер запущен.
2. Проверьте адрес и порт **8443**.
3. Для подключения из локальной сети проверьте правила брандмауэра на компьютере сервера.
4. Проверьте, что адрес в CraftBiker совпадает с DNS-именем или IP-адресом в SAN сертификата сервера.
5. Убедитесь, что порт **8080** доступен при первичной загрузке сертификата.

### Сертификат не принимается

Сверьте отпечаток в CraftBiker с отпечатком в личном кабинете. Не подтверждайте сертификат с неизвестным отпечатком. При законной замене сертификата используйте **Обновить сертификат**.

### Не удаётся войти

Проверьте логин, пароль, состояние учётной записи и назначенные роли в личном кабинете сервера. Убедитесь, что выбран правильный профиль подключения.

### Открывается предупреждение в Chrome

Доверие сертификату в CraftBiker действует только внутри приложения. Чтобы убрать предупреждение Chrome, публичный сертификат нужно отдельно добавить в доверенные сертификаты Windows; подробные шаги описаны в README проекта сервера: [bike_server/README.md](../bike_server/README.md).
